## True or False

Python can compare things. Every comparison gives back a **boolean**: either `True` or `False`.

```python
print(5 > 3)
print(5 < 3)
print(5 == 5)
print(5 != 5)
print("cat" == "cat")
print("cat" == "Cat")
```

Notice `==` with two equals signs. One `=` stores a value. Two `==` ask "are these the same?". Mixing them up is a classic mistake.

| Comparison | Meaning |
|---|---|
| `==` | equal to |
| `!=` | not equal to |
| `<` `>` | less than, greater than |
| `<=` `>=` | less than or equal, greater than or equal |

## if

An `if` statement runs a block of code only when the condition is `True`. The block is the indented lines underneath. Indent with 4 spaces (the Tab key does this for you here).

```python
temperature = 32
if temperature > 30:
    print("It is hot!")
    print("Drink water.")
print("This line always runs")
```

Two details that matter a lot:

- The `if` line ends with a colon `:`
- The lines that belong to the `if` are indented. The first unindented line is outside the `if`.

Change `temperature` to 20 and run again. The indented lines are skipped.

## else

`else` runs when the condition is `False`.

```python
age = int(input("How old are you? "))
if age >= 13:
    print("You can make an account.")
else:
    print("Ask a parent to help.")
```

## elif

For more than two possibilities, chain conditions with `elif` ("else if"). Python checks them top to bottom and runs only the **first** one that is `True`.

```python
score = 87
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
else:
    print("Keep practicing")
```

Order matters. If you put `score >= 70` first, an 87 would print `C`, because 87 is also greater than 70.

## Combining conditions

`and` needs both sides to be true. `or` needs at least one. `not` flips a boolean.

```python
age = 14
has_ticket = True

if age >= 13 and has_ticket:
    print("Welcome to the movie")

if age < 5 or age > 65:
    print("Discount!")
else:
    print("Full price")

print(not has_ticket)
```

## Checking what is inside a string

`in` checks whether something is contained in something else.

```python
answer = "I like Python and pizza"
if "pizza" in answer:
    print("Good taste")
if "broccoli" not in answer:
    print("No broccoli, noted")
```

::: tip
To compare text the user typed without caring about capitals, lower it first: `if answer.lower() == "yes":`

::: exercise id=if-fizz title="Fizz Buzz"
A famous programmer puzzle. Ask for a number (prompt `Number: `). Then:

- If it is divisible by both 3 and 5, print `FizzBuzz`
- Otherwise if divisible by 3, print `Fizz`
- Otherwise if divisible by 5, print `Buzz`
- Otherwise print the number itself

"Divisible by 3" means `number % 3 == 0`.

```python

```
--- tests
[
  {"name": "15 is FizzBuzz", "stdin": ["15"], "last_line": "FizzBuzz"},
  {"name": "9 is Fizz", "stdin": ["9"], "last_line": "Fizz"},
  {"name": "10 is Buzz", "stdin": ["10"], "last_line": "Buzz"},
  {"name": "7 is just 7", "stdin": ["7"], "last_line": "7"},
  {"name": "30 is FizzBuzz", "stdin": ["30"], "last_line": "FizzBuzz"}
]
--- hints
- Check the "both" case first, or 15 will print Fizz and stop.
- "both" means: number % 3 == 0 and number % 5 == 0
--- solution
```python
number = int(input("Number: "))
if number % 3 == 0 and number % 5 == 0:
    print("FizzBuzz")
elif number % 3 == 0:
    print("Fizz")
elif number % 5 == 0:
    print("Buzz")
else:
    print(number)
```

## What you learned

- Comparisons give `True` or `False`. `==` compares; `=` assigns.
- `if` / `elif` / `else` pick one path. Colons and indentation define the blocks.
- `and`, `or`, `not` combine conditions. `in` checks membership.
